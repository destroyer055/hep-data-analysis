# 质子与12C在水中阻止本领的数值计算与可视化

基于 LISE++ 导出的阻止本领数据，采用剩余射程法计算粒子在水中的能量损失率（dE/dx），并绘制完整的布拉格曲线。

## 功能概述

- 读取 LISE++ 导出的txt格式阻止本领表
- 构建三次样条插值模型，实现剩余射程与每核子能量之间的双向映射
- 计算全程 S(x) = -dE/dx，并对粒子停止前的最后数十微米进行高分辨率采样
- 输出两张可直接用于报告的图片：
  - 全程双对数坐标布拉格曲线
  - 末端放大图（清晰展示布拉格峰下降沿）

README.md

## 备注

- 本项目源于核物理实验方法课程的实验设计，旨在理解带电粒子在介质中的能量损失机制。
- LISE++ 数据来源：http://lise.nscl.msu.edu/
- 低能段（<0.001 MeV/u）的外推结果可靠性下降，末端放大图中已自动滤除。
